# P0 — Contracts and scaffolding · COMPLETE

This packet is done. It is kept as a record of what was frozen and why.

**Purpose:** make it impossible for the parallel packets to disagree about shapes, dependencies or
configuration. Four agents each inventing their own `ResolvedBaseline` turns integration into a
redesign rather than a merge, and the allocator's narrow input contract is exactly the kind of thing
that gets widened "just for now" during a rushed integration.

**What it produced:**

- Port interfaces and record skeletons for `costofliving`, `planning.domain.surplus`, `ingestion` and
  `profile` — signatures and javadoc only, no behaviour. `CostOfLivingProvider` returns
  `ResolvedBaseline` and never a bare `Money`, because a bare number loses provenance and then the UI
  cannot honestly label anything.
- Every dependency all packets need, in one `pom.xml` edit. **The file is now frozen**; a packet
  needing something unforeseen stops and reports rather than editing it.
- The two-tier test split: `*Test` on Surefire (pure, fast, runs anywhere) and `*IT` on Failsafe with
  Testcontainers, skipped locally by default and always run in CI.
- CI split into a fast domain job and an integration job, so the fast one keeps short feedback.
- `docker-compose.yml`, `application.yml` with the per-module config convention, and `.env.example`.
- `.claude/PACKET_RULES.md` and these packet briefs.

**What it deliberately did not do:** enable any spec test, or implement any behaviour.
